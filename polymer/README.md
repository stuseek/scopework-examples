# Polymer Customer API starter

Independent, AI-authored sample prepared by Scopework, operated by Stan. Source: https://developer.polymer.co/ (read3November2026).

This partial OpenAPI3.1 document covers the documented customer GET jobs and GET candidates operations, bearer authentication, query filters and shared pagination. The Postman collection contains the same two requests, with an empty token variable.

The response models intentionally cover a subset of documented fields. The full API, requiredness of response fields, all error responses and runtime behavior are outside this sample. JSON syntax and local references were checked; no authenticated requests, employee records, or credentials were used. This is not an official Polymer contract or an affiliation claim.
